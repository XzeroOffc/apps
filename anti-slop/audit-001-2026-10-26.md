# Audit UI SONORA — Search dan Lyrics

Tanggal: 2026-10-26  
Ruang lingkup: halaman Search, Player, dan jalur menuju hasil pencarian serta lirik pada `MainActivity.kt`.

## Temuan

1. **HIGH — Search dan Player masih berupa halaman Coming Soon (R-26).** Kedua route diarahkan ke `ComingSoonScreen`; tidak ada kolom pencarian, hasil lagu yang dapat dipilih, atau tampilan lyrics. Alur yang diminta belum dapat digunakan.

2. **HIGH — Status permintaan data belum ditampilkan (R-27).** Belum ada tampilan loading, hasil kosong, atau error untuk pencarian lagu maupun lyrics. Setelah endpoint dipanggil, pengguna perlu mendapat status dan tindakan lanjut yang jelas saat permintaan berjalan, tidak menemukan hasil, atau gagal.

## Catatan implementasi

Endpoint yang diberikan memakai parameter `apikey`, tetapi API key belum disertakan. Integrasi jaringan juga perlu menambahkan izin `INTERNET` di manifest. Kunci API sebaiknya tidak ditanam langsung di source APK yang dibagikan.
